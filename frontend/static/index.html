Architectural Evaluation & Analysis

Why Dynamic Load Balancing Excels

In distributed systems with variable hardware or intermittent database bottlenecks, simple Round Robin causes head-of-line blocking. By computing a weighted composite penalty, Dynamic Load Balancing dampens queue spikes while keeping healthy nodes saturated.

Understanding Load Imbalance (CV)

The Coefficient of Variation (\(CV = \sigma / \mu\)) measures request count deviation. While Round Robin boasts the lowest CV (\(0.0017\)), equal distribution is not optimal when backend latencies diverge. Least Connections and Dynamic balancing deliberately accept higher CV to protect response time SLAs.
